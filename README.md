# 📊 CodeAlpha Internship – Task 2: Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) using Python on a Synthetic Retail Sales Dataset. The objective is to explore sales data, identify trends and patterns, detect data quality issues, and generate meaningful business insights.

## 🎯 Objectives
- Understand dataset structure and data types.
- Identify missing values and duplicate records.
- Analyze sales trends across categories and regions.
- Perform statistical analysis and hypothesis testing.
- Detect potential outliers.
- Create meaningful data visualizations.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## 📂 Project Files
- `eda_analysis.py` – Complete Python EDA code.
- `retail_sales.csv` – Synthetic retail sales dataset.
- `requirements.txt` – Required Python libraries.
- `eda_outputs/` – Generated charts and analysis report.

## 🔍 Analysis Performed

1. Data Loading and Exploration
2. Data Cleaning
3. Missing Value Detection
4. Duplicate Record Detection
5. Statistical Analysis
6. Sales Trend Analysis
7. Hypothesis Testing
8. Outlier Detection using IQR
9. Data Visualization
10. Business Insights and Conclusion

## 📈 Visualizations
The project generates the following visualizations:

- Sales Distribution
- Category-wise Sales Analysis
- Monthly Sales Trends
- Correlation Heatmap
- Sales Outlier Detection
